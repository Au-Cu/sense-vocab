## 当前产品与数据

- 运行时词库：6,607 个单词、10,300 个义项、2 本词书；考研 5,042 词/7,983 义项，雅思 4,827 词/7,570 义项。
- 两本词书共享内容身份，但学习状态、计划、历史、日历和统计相互隔离；考研词汇是默认词书。
- 核心能力包括义项级学习状态机、学习日/自然日和跨午夜窗口、游客与账户隔离缓存、CAS 与版本向量同步、邮箱 OTP、反馈与管理后台、易混词球体、多发音、词形、单词列表与移动端流程；单词列表搜索同时支持英文子串和中文义项检索，中文结果支持规范化、模糊匹配及基于词义关系的近义候选排序。
- 主导航低频入口已统一为“更多”；其中“用户界面”允许用户在默认经典界面与新版液态玻璃界面之间切换。液态玻璃覆盖主页、统计、单词列表/词卡、学习、数据、弹窗和浮动导航，并为减少动态、减少透明度、增强对比度及不支持背景模糊的浏览器提供降级。偏好只保存在当前设备，不进入游客/账户学习数据或云端同步；缺失、无效或不可写时回退经典界面。
- 学习卡在主动完成并进入下一张或本组完成时提供一次轻量动效、可选提示音和支持设备上的 15ms 触觉反馈；卡片行显示当前阶段单词进度，顶部显示按义项汇总的全进度条，不写入学习状态或同步快照。主页与学习页、主页与单词列表之间使用从触发按钮位置扩散/收拢的层级遮罩：主页与底部导航作为同一父层，子页面展开时同时覆盖二者，退出时再同步露出，过渡期间底层导航不可交互；词卡展开与相邻/历史词切换使用旧、新卡片重叠衔接的卡片级过渡，旧画面保留至新画面接管，避免空白闪帧。熟知义项先在输入帧立即缩小，短暂停留后使用 FLIP 下移；布局读取、完整状态序列化和云端通知避开输入首帧，页面隐藏或离开时仍强制完成待处理本地保存。提前学习只提供一次，计划已经提前后不再显示或接受“再提前一天”操作。
- 统计数据已从主页内容流中独立出来，入口位于主页底部导航；主页与统计数据是平行页面，使用水平推入/退出过渡。页面包含每日学习量、词书进度、强化与复习池趋势、义项转化率、状态停留时间和义项状态流转。默认按当前词书和义项口径显示，支持词书、单词/义项及 21/42/90 天筛选；强化/复习池和对应停留时间属于连续状态存量，无学习日沿用最近可靠快照并按自然时间推进，不能因当天没有学习事件而断线。转化率只使用可确认的学习结果作分母；存在可靠转化历史后，无学习日的 `0/0` 按 0% 连续绘制，旧强化记录缺少失败结果时不再把只有成功事件的记录误报为 100%。既有学习数据继续保留，无法精确还原的历史日期显示为空态。图表折线与图例使用一致且可区分的系列色，时间窗默认定位到最新数据，坐标轴固定在横向绘图区外；每日学习量以 0 为下界，其余时序折线按当前横向可见窗口的有效最小值和最大值动态缩放，避免远端异常值压扁当前窗口。时序图把日期放在标题行右侧，其余序列数据使用无内部滚动的紧凑详情行，按可用宽度排成一行或最多两行，并与图表保持一致间距；鼠标或触摸只需对齐日期的横向范围即可吸附并显示竖向指示线。义项状态流转按稳定 `senseId` 去重，以四列横向桑基图展示；复习到强化的回退只在终点列展开一个“待强化”节点，节点高度和带宽按流量缩放，流带跟随流出状态色并使用同色柔光粒子，流出占比按起始状态计算。手机默认完整容纳全图，待强化和待复习标签位于对应柱体下方，并支持有界缩放和拖动；可见的重复流转明细表已移除，读屏摘要继续保留。
